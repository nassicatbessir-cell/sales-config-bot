# Sales Config Bot

ربات فروش اشتراک تلگرام با انتخاب پلن، پرداخت کارت‌به‌کارت، دریافت رسید، تأیید دستی مدیر و تحویل اشتراک از داخل تلگرام.

## امکانات

- چهار پلن قابل تنظیم در `src/plans.js`
- دریافت رسید تصویر یا PDF و ارسال مستقیم آن برای مدیر
- تأیید یا رد سفارش با دکمه‌های داخلی مدیر
- تحویل متن، فایل یا کانفیگ اشتراک پس از تأیید پرداخت
- ذخیره دائمی سفارش‌ها در PostgreSQL
- اعتبارسنجی تنظیمات ضروری در زمان شروع
- بدون ذخیره‌سازی توکن یا اطلاعات بانکی در GitHub

## راه‌اندازی روی Render

1. این مخزن را به Render متصل کنید.
2. یک **PostgreSQL** بسازید و مقدار **Internal Database URL** آن را برای `DATABASE_URL` قرار دهید.
3. یک **Background Worker** از این مخزن بسازید (یا از `render.yaml` استفاده کنید).
4. در Environment Variables مقادیر واقعی زیر را فقط در Render وارد کنید:

```env
BOT_TOKEN=توکن_جدید_ربات
ADMIN_ID=شناسه_عددی_تلگرام_مدیر
DATABASE_URL=آدرس_اتصال_PostgreSQL
CARD_NUMBER=شماره_کارت
CARD_HOLDER=نام_دارنده_کارت
SUPPORT_USERNAME=@نام_پشتیبانی
```

5. Start Command را `npm start` قرار دهید.
6. پس از استقرار، در تلگرام `/start` را برای ربات ارسال کنید و یک سفارش آزمایشی تا مرحلهٔ تحویل بسازید.

> هیچ مقدار واقعی را در GitHub، README یا فایل‌های commit‌شده وارد نکنید. هر توکنی که قبلاً در مخزن یا گفتگو نوشته شده باید در BotFather لغو و با توکن جدید جایگزین شود.

## گردش سفارش

1. کاربر `/start` یا `/plans` را می‌زند و پلن انتخاب می‌کند.
2. ربات مبلغ و شماره کارت را نمایش می‌دهد.
3. کاربر رسید JPG، PNG یا PDF می‌فرستد.
4. مدیر رسید را با دکمه تأیید یا رد بررسی می‌کند.
5. پس از تأیید، مدیر دکمه «تحویل اشتراک» را می‌زند.
6. مدیر متن، فایل یا کانفیگ را در پیام بعدی ارسال می‌کند؛ ربات همان محتوا را برای خریدار می‌فرستد و سفارش را تحویل‌شده ثبت می‌کند.

## عملیات امن

- فقط `ADMIN_ID` امکان تأیید، رد و تحویل سفارش را دارد.
- رسید فقط برای سفارش در وضعیت دریافت رسید پذیرفته می‌شود و سفارش دوباره قابل بررسی نیست.
- برای هر بار استقرار، مقادیر محرمانه را در متغیرهای محیطی Render نگه دارید؛ هرگز آن‌ها را commit نکنید.
